Gyan Niketan — Admin

Sign in with your GitHub account to manage notices and photos.

Create a fine-grained token at github.com/settings/tokens. Set Repository access to Only this repository, and Permissions → Contents to Read and write. Copy the token here.

  1. Go to github.com/settings/tokens?type=beta
  2. Click Generate new token
  3. Name it gyan-niketan-admin, expiry e.g. 90 days
  4. Repository access → Only select repositories → pick your repo
  5. Permissions → Contents: Read and write
  6. Generate, copy the token, paste it above

The token is stored only in this browser. Click Sign out when using a shared computer.
